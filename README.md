# QuizGame
It's a Quiz Game.

Should just be Download, Unzip, put somewhere sensible, and run the main.py file.
Uses PyGame to play Audio Clips.
If the poland.py file is enabled, (lines 1429-1431 of window_controls.py need to be uncommented), then Pillow and ImageTK will need to be installed, if not already.

I have spent like, 1.5 months on this working at stupid times because it's when I wanted to work on it.
Hopefully I haven't missed any major issues, and if any do exist they are just minor ones, but I don't think there are any.
